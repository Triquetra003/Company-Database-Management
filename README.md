Product Management Portal
A simple product management system with secure authentication using Argon2 password hashing and password expiry functionality.

Features
User Authentication

Sign in with email and password

Password management using Argon2 hashing

Password expiry mechanism

Registration Form

Register employed products and clients

Simple HTML form submission

Search & Filter

Search and filter tables

Filter by name, email, and other fields

Dynamic filtering based on selected criteria

Technology Stack
Backend: Python (Flask server)

Database: PostgreSQL

Frontend: HTML, CSS, JavaScript

Password Hashing: Argon2

Installation
Prerequisites
Python 3.8+

PostgreSQL
